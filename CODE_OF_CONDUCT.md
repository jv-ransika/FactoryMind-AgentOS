# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free
experience for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent and focus on technical facts.
- Accept feedback professionally.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Publishing private information without consent.
- Disruptive or abusive communication.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, and
other contributions that violate this Code of Conduct.

For reporting concerns, open a private security/contact channel with project
maintainers.
