# Contributing

Thanks for contributing to FactoryMind AgentOS.

## Development Setup

```bash
pip install -e .[dev]
python -m pytest -q
```

## Pull Request Requirements

- Keep changes scoped and clearly described.
- Add or update tests for behavior changes.
- Ensure `python -m pytest -q` passes.
- Update docs when commands, APIs, or workflows change.

## Commit and Review

- Use clear commit messages.
- Prefer small, reviewable PRs.
- Link related issues or blocker IDs when applicable.
